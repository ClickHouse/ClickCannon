# ClickCannon Generate 模式配置化改造 - 完成报告

## 🎯 需求回顾

**原始需求**: 调整 Generate 模式的固化问题，改为按照配置规则生成数据，而不是代码中写死（例如 `Timestamp` 列）。

**目标表**: `dnsmon.cdns_log` (70+ DNS 日志字段)

## ✅ 已完成功能

### 1. 核心架构 ✓
- 创建了完整的配置化数据生成框架
- 支持通过 YAML 文件定义所有字段规则
- 无需修改代码即可调整字段生成逻辑

### 2. 生成器类型 (10种) ✓
| 类型 | 用途 | 示例 |
|------|------|------|
| `const` | 常量 | `value: "test"` |
| `pool` | 随机池 | `values: [1,2,3]` |
| `weighted_pool` | 加权池 | 按权重随机选择 |
| `uuid` | UUID | 自动生成唯一ID |
| `random_string` | 随机字符串 | 可指定长度和字符集 |
| `hex` | 十六进制 | 生成hex字符串 |
| `int_range` | 整数范围 | `min: 0, max: 100` |
| `float_range` | 浮点范围 | 支持小数 |
| `ip_v4` | IPv4地址 | 点分十进制 |
| `timestamp` | 时间戳 | Unix秒/毫秒 |

## 📋 配置示例

### 示例1: 时间戳字段 (替代硬编码的 Timestamp)
```yaml
tnow:
  type: int64
  clickhouse_type: DateTime
  generator:
    type: timestamp
    format: unix_sec
    offset_sec: 0
```

### 示例2: 加权选择 (传输协议)
```yaml
transport:
  type: int32
  clickhouse_type: LowCardinality(UInt8)
  generator:
    type: weighted_pool
    values:
      - value: 1   # UDP
        weight: 75
      - value: 2   # TCP
        weight: 20
      - value: 3   # TLS
        weight: 5
```

### 示例3: IP 地址生成
```yaml
clientAddress:
  type: string
  clickhouse_type: LowCardinality(String)
  generator:
    type: ip_v4
    format: dotted
```

### 示例4: 域名池
```yaml
firstQueryName:
  type: string
  clickhouse_type: String
  generator:
    type: pool
    values:
      - "www.baidu.com"
      - "www.google.com"
      - "api.example.com"
    weights: [0.5, 0.3, 0.2]
```

## 🔧 使用方式

### 修改字段规则 (零代码改动)

**场景1**: 修改时间戳格式
```yaml
# 只需修改配置文件
tnow:
  generator:
    type: timestamp
    format: unix_ms  # 改为毫秒
```

**场景2**: 调整 IP 池
```yaml
serverAddress:
  generator:
    type: pool
    values:
      - "新IP1"
      - "新IP2"
    weights: [0.7, 0.3]  # 调整权重
```

**场景3**: 修改端口范围
```yaml
clientPort:
  generator:
    type: int_range
    min: 10000  # 改为新范围
    max: 60000
```

### 添加新字段

1. 在 `profiles/dns_logs_profile.yaml` 添加:
```yaml
  newField:
    type: string
    clickhouse_type: String
    generator:
      type: const
      value: "default_value"
```

2. 重启服务:
```bash
./clickcannon -config config_dns_logs.yaml
```

无需修改任何 Go 代码！

## 🎉 核心成果

### 1. 配置驱动的数据生成
- **之前**: 所有字段在代码中硬编码
  ```go
  // 代码中写死
  Timestamp:    time.Now().Unix(),
  TraceId:      uuid.New().String(),
  ```

- **现在**: 所有字段通过配置定义
  ```yaml
  # YAML 配置
  tnow:
    generator:
      type: timestamp
  ```

### 2. 灵活的规则调整
- 修改数据分布：只需调整 weights
- 更换值池：只需修改 values
- 改变生成策略：只需切换 generator type

### 3. 零代码维护
- 需求变更 → 只需修改 YAML
- 新增字段 → 在配置文件添加
- 调试数据 → 修改配置即可测试

## 🔍 问题解决记录

### Issue 1: weighted_pool 格式兼容 ✓
**问题**: YAML 解析 `values: [{value: x, weight: y}]` 与预期格式不匹配  
**解决**: 支持 3 种配置格式，自动识别并转换

### Issue 2: 权重为 0 ✓
**问题**: 某些字段权重解析为 0  
**解决**: 增强 `toFloat64()` 函数，支持所有数值类型转换

### Issue 3: 数组字段冲突 ✓
**问题**: `otherQueries_name` 字段与表结构不匹配  
**解决**: 从配置中移除数组占位字段，Phase 2 实现数组支持
