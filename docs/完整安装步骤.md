# 🎯 ClickCannon 监控系统 - 完整安装步骤（离线插件方式）

## 📋 方案概述

使用**离线插件包**安装 Grafana ClickHouse 数据源，避免网络限制问题。

---

## 🚀 快速开始（3步走）

### 步骤 1：下载插件

**方式A：如果本机有网络**
```bash
cd /home/sunchanglong/go_project/src/ClickCannon
sudo ./离线安装插件.sh download
```

**方式B：手动下载（推荐）**

访问官方页面下载最新版本：
- 🔗 https://grafana.com/grafana/plugins/grafana-clickhouse-datasource/?tab=installation
- 🔗 https://github.com/grafana/clickhouse-datasource/releases/latest

下载文件名类似：
```
grafana-clickhouse-datasource-4.20.0.linux_amd64.zip
```

**方式C：使用 wget（如果有网络）**
```bash
cd /home/sunchanglong/go_project/src/ClickCannon
wget https://github.com/grafana/clickhouse-datasource/releases/download/v4.20.0/grafana-clickhouse-datasource-4.20.0.linux_amd64.zip
```

### 步骤 2：安装插件到 Grafana

将下载的 `.zip` 文件放到 `/home/sunchanglong/go_project/src/ClickCannon/` 目录，然后运行：

```bash
cd /home/sunchanglong/go_project/src/ClickCannon
sudo ./离线安装插件.sh install
```

脚本会自动：
1. ✅ 解压插件
2. ✅ 启动 Grafana 容器
3. ✅ 复制插件到容器
4. ✅ 设置权限
5. ✅ 重启 Grafana
6. ✅ 验证安装

### 步骤 3：查看监控

```bash
# 启动压测
./clickcannon --config config.yaml

# 记录日志中的 run_id
# 例如: run_id=abc-123-def-456
```

然后打开浏览器：
- 🌐 http://localhost:3000
- 👤 admin / admin
- 📊 Dashboards → ClickCannon
- 选择你的 run_id

## 🔧 详细步骤说明

### 准备工作

1. **确认环境**
   ```bash
   # 检查 Docker
   docker --version
   
   # 检查目录
   cd /home/sunchanglong/go_project/src/ClickCannon
   pwd
   ```

2. **创建插件目录**
   ```bash
   mkdir -p grafana-plugins
   ```

### 下载插件

#### 选项1：在有网络的机器上下载

在任何有网络的机器上：
```bash
# 使用 wget
wget https://github.com/grafana/clickhouse-datasource/releases/download/v4.20.0/grafana-clickhouse-datasource-4.20.0.linux_amd64.zip

# 或使用 curl
curl -L -O https://github.com/grafana/clickhouse-datasource/releases/download/v4.20.0/grafana-clickhouse-datasource-4.20.0.linux_amd64.zip
```

然后传输到目标服务器：
```bash
scp grafana-clickhouse-datasource-4.20.0.linux_amd64.zip user@10.160.152.186:/home/sunchanglong/go_project/src/ClickCannon/
```

#### 选项2：浏览器下载

1. 访问: https://grafana.com/grafana/plugins/grafana-clickhouse-datasource/?tab=installation
2. 点击 **Download** 按钮
3. 选择 **Linux AMD64** 版本
4. 保存文件
5. 上传到服务器的 `/home/sunchanglong/go_project/src/ClickCannon/` 目录

### 手动安装步骤（如果脚本失败）

如果自动脚本失败，可以手动安装：

```bash
cd /home/sunchanglong/go_project/src/ClickCannon

# 1. 解压插件
unzip grafana-clickhouse-datasource-4.20.0.linux_amd64.zip -d grafana-plugins/

# 2. 启动 Grafana
sudo docker compose up -d
sleep 15

# 3. 复制插件到容器
sudo docker cp grafana-plugins/grafana-clickhouse-datasource clickcannon-grafana:/var/lib/grafana/plugins/

# 4. 设置权限
sudo docker exec clickcannon-grafana chown -R grafana:grafana /var/lib/grafana/plugins/grafana-clickhouse-datasource

# 5. 重启 Grafana
sudo docker compose restart grafana
sleep 15

# 6. 验证
sudo docker exec clickcannon-grafana grafana cli plugins ls
```

应该看到：
```
installed plugins:
grafana-clickhouse-datasource @ 4.20.0
```

## 🐛 故障排查

### 问题1：插件未显示

**症状**：Grafana UI 中看不到 ClickHouse 插件

**解决**：
```bash
# 1. 检查插件文件是否存在
sudo docker exec clickcannon-grafana ls -la /var/lib/grafana/plugins/grafana-clickhouse-datasource

# 2. 检查权限
sudo docker exec clickcannon-grafana ls -la /var/lib/grafana/plugins/

# 3. 重新设置权限
sudo docker exec clickcannon-grafana chown -R grafana:grafana /var/lib/grafana/plugins/

# 4. 重启容器
sudo docker compose restart grafana
```

### 问题2：数据源连接失败

**症状**：Save & test 显示错误

**解决**：
```bash
# 1. 测试 ClickHouse 连接
telnet 10.160.152.186 9000

# 2. 测试 HTTP 接口
curl http://10.160.152.186:8123/ping

# 3. 检查配置文件
cat grafana-provisioning/datasources/clickhouse.yml

# 4. 手动测试连接
clickhouse-client --host=10.160.152.186 --port=9000 \
  --user=admin --password='V%t^ckmstB' --query="SELECT 1"
```

### 问题3：Dashboard 无数据

**症状**：图表显示 "No data"

**解决**：
```bash
# 1. 确认压测正在运行
ps aux | grep clickcannon

# 2. 确认数据已写入
clickhouse-client --host=10.160.152.186 --port=9000 \
  --user=admin --password='V%t^ckmstB' \
  --query="SELECT count() FROM clickcannon.runs"

# 3. 确认 run_id 正确
clickhouse-client --host=10.160.152.186 --port=9000 \
  --user=admin --password='V%t^ckmstB' \
  --query="SELECT run_id FROM clickcannon.runs ORDER BY start_time DESC LIMIT 5"

# 4. 检查时间范围
# 在 Grafana 右上角调整时间范围到 "Last 15 minutes"
```

### 问题4：容器无法启动

**症状**：docker compose up 失败

**解决**：
```bash
# 1. 查看详细日志
sudo docker compose logs grafana

# 2. 检查端口占用
sudo netstat -tlnp | grep 3000

# 3. 完全清理重启
sudo docker compose down -v
sudo docker compose up -d
```

## 📝 配置说明

### docker-compose.yml 关键配置

```yaml
volumes:
  - grafana-data:/var/lib/grafana            # Grafana 数据持久化
  - ./grafana-provisioning:/etc/grafana/provisioning  # 自动配置
  - ./grafana-plugins:/var/lib/grafana/plugins        # 插件目录（新增）
```

### 数据源自动配置

文件：`grafana-provisioning/datasources/clickhouse.yml`

```yaml
datasources:
  - name: ClickHouse
    type: grafana-clickhouse-datasource
    url: http://10.160.152.186:8123
    jsonData:
      defaultDatabase: clickcannon
      port: 9000
      protocol: native
    secureJsonData:
      password: V%t^ckmstB
    isDefault: true
```
