## 🔑 关键技术点

### 1. 指标收集机制
- ClickCannon 自动将指标写入 `clickcannon.runs` 和 `clickcannon.perf` 表
- 每个运行有唯一的 `run_id`
- 支持自定义属性标签（attributes）

### 2. Grafana 集成
- 使用官方 `grafana-clickhouse-datasource` 插件
- 通过 provisioning 机制自动配置数据源和 Dashboard
- 无需手动导入，开箱即用

### 3. 持续压测设计
- `loop: true` 实现文件循环读取
- `shift_timestamp: now` 避免时间戳重复
- `block_retirement_uses` 控制内存增长

### 4. 高性能配置
- 多线程并发：disk 8线程 + insert 8线程
- 大批次提交：batch_size = 100000
- 高速限制：mb_per_second_limit = 10240 (10 GiB/s)
