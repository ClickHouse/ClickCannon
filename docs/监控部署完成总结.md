### 监控表结构

| 表名 | 用途 | 关键字段 |
|------|------|----------|
| `clickcannon.runs` | 运行记录 | run_id, name, data_type, start_time |
| `clickcannon.perf` | 性能指标 | run_id, metric_name, value, timestamp |

### 关键指标

- **disk_bytes_uncompressed_total** - 磁盘读取字节数
- **insert_bytes_uncompressed_total** - 插入字节数
- **insert_rows_total** - 插入行数
- **insert_batches_total** - 批次数
- **insert_errors_total** - 错误数（应为0）

## 🔧 配置说明

### config.yaml - 指标配置

```yaml
metrics:
  enabled: true                              # ✅ 已启用
  clickhouse_dsn: tcp://10.160.152.186:9000  # ✅ 已配置
  database: clickcannon                      # ✅ 已配置
  run_table: runs                            # ✅ 已配置
  metrics_table: perf                        # ✅ 已配置
  create_schema: true                        # ✅ 自动建表
```

### docker-compose.yml

```yaml
services:
  grafana:
    image: grafana/grafana:11.5.0            # ✅ 稳定版本
    network_mode: host                       # ✅ 使用宿主机网络
    volumes:
      - ./grafana/data:/var/lib/grafana      # ✅ 数据持久化
      - ./grafana/provisioning:/etc/grafana/provisioning  # ✅ 自动配置
```
