# 🔧 Grafana 网络问题解决方案

## 问题说明
Grafana 容器无法从互联网下载 ClickHouse 插件（超时错误）：
```
Error: ✗ Get "https://grafana.com/api/plugins/repo/grafana-clickhouse-datasource": 
context deadline exceeded (Client.Timeout exceeded while awaiting headers)
```

## 🎯 解决方案（按推荐顺序）

---

### ✅ 方案1：先启动 Grafana，再在容器内安装插件（推荐）

**步骤1：停止并清理当前容器**
```bash
cd /home/sunchanglong/go_project/src/ClickCannon
sudo docker compose down -v
```

**步骤2：启动 Grafana（不自动安装插件）**
```bash
sudo ./start-monitoring.sh
```

插件会自动在容器内安装。如果网络仍然超时，看方案2。

---

### ✅ 方案2：手动在容器内安装插件

**步骤1：启动 Grafana**
```bash
cd /home/sunchanglong/go_project/src/ClickCannon
sudo docker compose up -d
```

**步骤2：等待启动完成**
```bash
sleep 10
curl http://localhost:3000
```

**步骤3：在容器内安装插件**
```bash
sudo docker exec clickcannon-grafana grafana cli plugins install grafana-clickhouse-datasource
```

**步骤4：重启容器**
```bash
sudo docker compose restart grafana
```

**步骤5：验证**
```bash
sleep 10
curl http://localhost:3000
```

然后打开浏览器访问 http://localhost:3000

---

### ✅ 方案3：使用本地离线插件包

如果网络完全无法访问 grafana.com，使用离线安装：

**步骤1：下载插件到本地（在有网络的机器上）**
```bash
# 方式A：使用 wget
wget https://github.com/grafana/clickhouse-datasource/releases/download/v4.5.3/grafana-clickhouse-datasource-4.5.3.linux_amd64.zip

# 方式B：使用 curl
curl -L -O https://github.com/grafana/clickhouse-datasource/releases/download/v4.5.3/grafana-clickhouse-datasource-4.5.3.linux_amd64.zip
```

**步骤2：传输文件到目标服务器**
```bash
scp grafana-clickhouse-datasource-4.5.3.linux_amd64.zip user@10.160.152.186:/home/sunchanglong/go_project/src/ClickCannon/
```

**步骤3：解压插件**
```bash
cd /home/sunchanglong/go_project/src/ClickCannon
unzip grafana-clickhouse-datasource-4.5.3.linux_amd64.zip -d /tmp/
```

**步骤4：复制到 Grafana 容器**
```bash
sudo docker compose up -d
sleep 10
sudo docker cp /tmp/grafana-clickhouse-datasource clickcannon-grafana:/var/lib/grafana/plugins/
```

**步骤5：设置权限并重启**
```bash
sudo docker exec clickcannon-grafana chown -R grafana:grafana /var/lib/grafana/plugins/grafana-clickhouse-datasource
sudo docker compose restart grafana
```

**步骤6：验证插件已安装**
```bash
sleep 10
sudo docker exec clickcannon-grafana grafana cli plugins ls
```

应该看到：
```
installed plugins:
grafana-clickhouse-datasource @ 4.5.3
```

### ✅ 方案4：配置代理（如果有企业代理）

如果你的网络环境需要代理，修改 `docker-compose.yml`：

```yaml
services:
  grafana:
    image: grafana/grafana:latest
    container_name: clickcannon-grafana
    restart: unless-stopped
    ports:
      - "3000:3000"
    environment:
      - GF_SECURITY_ADMIN_USER=admin
      - GF_SECURITY_ADMIN_PASSWORD=admin
      - GF_USERS_ALLOW_SIGN_UP=false
      - HTTP_PROXY=http://your-proxy:port
      - HTTPS_PROXY=http://your-proxy:port
      - NO_PROXY=localhost,127.0.0.1
      - GF_INSTALL_PLUGINS=grafana-clickhouse-datasource
    volumes:
      - grafana-data:/var/lib/grafana
      - ./grafana-provisioning:/etc/grafana/provisioning
    networks:
      - clickcannon
```

---

### ✅ 方案5：使用预装插件的 Grafana 镜像

创建自定义 Dockerfile：

```dockerfile
FROM grafana/grafana:latest

# 离线安装插件
USER root
COPY grafana-clickhouse-datasource /var/lib/grafana/plugins/grafana-clickhouse-datasource
RUN chown -R grafana:grafana /var/lib/grafana/plugins/

USER grafana
```

修改 `docker-compose.yml`：
```yaml
services:
  grafana:
    build: .  # 使用本地 Dockerfile
    container_name: clickcannon-grafana
    # ... 其他配置不变
```

