## 📊 关键监控指标说明

你应该关注这些指标：

| 指标名称 | 含义 | 预期值 |
|---------|------|--------|
| `insert_rows_total` | 插入的总行数 | 持续增长 |
| `insert_bytes_uncompressed_total` | 插入的原始字节数 | 持续增长 |
| `insert_bytes_compressed_total` | 插入的压缩字节数 | < uncompressed |
| `disk_bytes_uncompressed_total` | 磁盘读取的字节数 | 持续增长 |
| `disk_rows_total` | 磁盘读取的行数 | 持续增长 |
| `insert_errors_total` | 插入错误数 | 应该为 0 |

### 计算吞吐量
```sql
-- 最近1分钟的插入速率
SELECT 
  formatReadableQuantity((max(value) - min(value)) / 60) as rows_per_second
FROM clickcannon.perf
WHERE run_id = 'YOUR_RUN_ID'
  AND metric_name = 'insert_rows_total'
  AND timestamp > now() - INTERVAL 1 MINUTE
```
